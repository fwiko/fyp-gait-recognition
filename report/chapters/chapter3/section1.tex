\section{Introduction}
\label{sec:new-ideas-introduction}

This chapter proposes \ac{gr}-based authentication as a solution to security and usability concerns with existing \ac{pacs} --- outlined in Chapter \ref{chap:context}.
It aims to demonstrate \ac{gr} as a less obtrusive authentication option that maintains the level of security provided by traditional authetication methods and the more common biometric authentication options.
